4. Backup Integrity & Restore Safeguards

SuperBaser executes physical snapshots using native PostgreSQL tools (pg_dumpall) inside ephemeral Cloudflare Containers. While SuperBaser employs two-stage conflict verification prior to restoration, you acknowledge that initiating a restore operation into a production database modifies schema objects and table records. Destructive restore requests require explicit confirmation before execution.
